# D

**Data Action Policy**
Enum (`DataActionPolicy` in `Sdk.Shared`) that defines whether binary tick files are kept, deleted, or cached after use. Values: `KeepUntilExit`, `DeleteAfterTask`, `PersistentCache`.

**Determinism**
The guarantee that identical inputs produce bit‑identical outputs every run, on any supported platform.

**Drawdown**
The percentage decline from a peak in equity. **Daily Drawdown** resets at the start of each UTC day.
