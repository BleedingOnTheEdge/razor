# Purpose

This document catalogues every configuration object, enumeration, and data contract that controls Razor engine behaviour. It is the single source of truth for parameter names, types, validation rules, and acceptable values. Use it when writing strategies, building adapters, or interpreting Cloud‑supplied payloads.
