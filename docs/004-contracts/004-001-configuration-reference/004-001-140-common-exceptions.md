# 14. Common Exceptions

| Exception | Namespace | Description |
|-----------|-----------|-------------|
| `ConfigurationException` | `Razor.Core.Sdk.Shared` | Thrown when a specification contains invalid values. |
| `AdapterException` | `Razor.Core.Sdk.Shared` | Thrown when an adapter operation fails. |
| `StrategyException` | `Razor.Core.Sdk.Shared` | Thrown when a strategy encounters an error. |
| `OptimizationException` | `Razor.Core.Sdk.Shared` | Thrown during GA optimisation failures. |
| `EngineException` | `Razor.Core.Engine.Core.Exceptions` | Base exception for engine‑specific errors. |
