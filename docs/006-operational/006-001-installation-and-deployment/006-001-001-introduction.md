# 1. Introduction

This guide explains how to install the Razor Engine on Windows and Linux servers, connect it to Razor Cloud, and verify correct operation. The engine is a lightweight, headless binary that runs your trading strategies and communicates with your chosen brokers through adapter extensions.

## 1.1 Who Should Read This

- Traders deploying Razor for live or paper trading.
- IT staff responsible for provisioning and maintaining trading servers.
- Extension developers testing their adapters, strategies, indicators, hook plugins, and neural network models locally.

## 1.2 What You Need

- A server or virtual machine meeting the minimum specifications.
- A Razor Cloud account (free or paid) with an API key for your engine instance.
- The Razor Engine binary archive for your operating system.
- Outbound network access to Razor Cloud and your broker's API.
