# Roadmap

The version-by-version delivery plan. Detailed future feature areas are in
`product:razor/blueprint/future-features`.

| Version | Highlights |
|---|---|
| **v1.0.0 LTS** | Stable engine with the hooks-and-slots extension system; adapter and strategy pluggability; Cloud MVP with remote commands, monitoring and reporting; encrypted transport; engine obfuscation; public `Sdk`. |
| **v1.5.0** | Enhanced reporting dashboards; performance improvements; live trading refinements; additional hook points for finer control. |
| **v2.0.0 LTS** | Multi-operation engine (concurrent live and optimisation); advanced marketplace with code signing; ONNX and reinforcement-learning models via `INeuralNetworkModel`; extension profiles and hot reload. |
| **v2.5.0** | Enterprise features: audit logs, compliance reports; performance optimisations for large datasets. |
| **v3.0.0 LTS** | Mature institutional platform: advanced analytics, multi-broker management, global market support. |
