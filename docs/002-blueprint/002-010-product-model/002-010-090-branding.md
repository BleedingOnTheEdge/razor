# Branding and Product Names

The canonical names. These are the only acceptable spellings; documentation, code and interfaces must
use them.

| Name | Refers to |
|---|---|
| **Razor** | The umbrella product. |
| **Razor Engine** | The execution node binary (the solution project is `Engine`; the product name adds the prefix). |
| **Razor Cloud** | The management and monitoring dashboard (the project is named exactly `Cloud`). |
| **Razor Marketplace** | The extension discovery and distribution service. |
| **`Sdk`** | The public SDK NuGet package (no `Razor.` prefix; the assembly is `Sdk`). |

Two naming rules follow from the code, which is authoritative for names:

- The Cloud project is named exactly **`Cloud`** - not `Razor.Cloud`, and not `Panel`.
- The SDK project is named exactly **`Sdk`** - not `Razor.Sdk`.
