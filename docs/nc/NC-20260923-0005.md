# NEED_CLARIFICATION: README Documentation Hub Links Stale

## 1. Context & Trigger
Reorganization of docs into modular directories resulted in stale relative links in repository and subproject `README.md` files.

## 2. Unresolved Question

- Pros: Functional navigation for human contributors.
- Cons: One-time manual link update required.

- Cons: Confusing dead links.

## 4. Resolution & Decision

- **Decision Rationale**: All documentation hub links in root and subproject README files were updated to canonical paths in `docs/` and verified.
