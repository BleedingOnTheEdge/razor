# NEED_CLARIFICATION: Org-root Anchor Unreachable

## 1. Context & Trigger
Original template expected a repo `AGENT.md` to name an `org_root`. Premise assumed razor was the sole repo.

## 2. Unresolved Question
Whether workspace root is a non-git container or anchored by an organization root.

## 3. Options Considered
### Option A: Assume razor is org root
- Pros: Self-contained.
- Cons: Inaccurate representation of workspace.

### Option B: Anchor razor at level repo with org-root present
- Pros: Accurately reflects existing org-root repository.
- Cons: None.
