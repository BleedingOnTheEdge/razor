# NEED_CLARIFICATION: Subtree Anchors Missing Subproject AGENT.md Manifests

## 1. Context & Trigger
Monorepo subprojects (`core/src/*`, `frontends/apps/*`, `frontends/packages/*`) lacked standardized subproject `AGENT.md` manifests under the enterprise governance hierarchy.

## 2. Unresolved Question
Whether each monorepo subproject requires its own architectural profile declaration (`AGENT.md`) with explicit boundaries and local Nx delegations.

## 3. Options Considered
### Option A: Standardize Subproject AGENT.md Manifests
- Pros: Complete compliance with enterprise multi-agent governance, explicit boundaries, profile enforcement.
- Cons: 10 new manifest files to maintain.

### Option B: Maintain Monolithic Single Root AGENT.md
- Pros: Fewer files.
- Cons: Ambiguous boundaries, lacks subproject profile enforcement and localized Nx mapping.

## 4. Resolution & Decision
- **Selected Option**: Option A
- **Decision Rationale**: Fully created and verified 10 subproject `AGENT.md` files conforming to Profile A/B/D specifications and verified with `scripts/verify-agent-manifests.py`.
- **Decided By**: Enterprise Architecture Lead
- **Date Decided**: 2026-10-13
- **Associated ADR**: docs/adr/0001-monorepo-nx-orchestration-and-enterprise-governance.md
